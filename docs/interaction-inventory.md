Authority: Figma file `zMX5mCBULzIdaPdMJ7wpfa`, code layer `2:3`; original specification and data package preserved in `source-package/Expande_paquete_para_Figma`.

Evidence: welcome, simulated access, home, challenge catalog/detail, applications overview, Explore and Account were inspected in the live prototype. Source links were returned by Figma but could not be read by the resource provider. Further Windows inspection failed with `GetCursorPos: Access is denied`. The remaining rows below are **specification-derived**, not claimed as a completed live-Figma audit. This distinction must remain visible in the verification report.

Every list supports loading, empty, recoverable error and partial/unknown data. Search/filter controls preserve their URL state. Forms retain entered values when API validation fails. Every mutation is session-scoped unless explicitly made through the catalog CLI.

The later user-supplied Expande brand manual controls the app's visual identity: extracted full logo lockups, Rubik, magenta/navy with mint/yellow accents, and original decorative motifs. This updates shared presentation across all routes while retaining the interactions below and the existing catalogue media. See [brand implementation](brand-implementation.md).
